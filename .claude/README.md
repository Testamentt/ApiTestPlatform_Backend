# .claude/ 目录说明

Claude Code 的项目级配置目录。**CLAUDE.md 只做渐进式披露**（保留红线摘要 + 指向本目录的索引），详细内容按需从本目录读取，避免每次会话携带无关上下文。

## 结构
- `rules/RULES.md` — 项目全局规则权威全文（代码质量、技术约束、工程化、目录分层、数据模型、错误处理、接口、Celery、LLM、安全、测试、SOP、Git、清单、示例、面试考点、开发流程 R1-R6、文档沉淀，共 18 节；§17 开发流程规则、§18 文档沉淀）
- `skills/` — 项目技能（每个技能一个子目录 + `SKILL.md`；仅当任务命中其 description 时才被加载）

## 约定
- CLAUDE.md 保持精简（红线 10 条 + 索引表），本目录承载细节
- **新增/修改规则** → 写入 `rules/RULES.md` 对应章节；若改动涉及红线或章节结构，同步更新 CLAUDE.md 的摘要与索引表
- **新增技能** → 在 `skills/` 下建目录 + `SKILL.md`，并考虑是否在 CLAUDE.md 的技能部分登记
