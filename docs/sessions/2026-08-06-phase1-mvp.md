# 会话沉淀：Phase 1 核心执行闭环 MVP（2026-08-06）

## 当前目标

跑通「创建用例 → 异步执行 → 查看结果」闭环（面试导向简化版），全程 Swagger UI。

## 关键约束

- 面试导向：MVP 零前端、无鉴权、无限流；RULES.md §2.4/§5.1/§5.2/§8.3 已放宽为 MVP 例外。
- 仅 2 张表（test_cases/tasks）；`create_all` 建表（Phase 4 切 Alembic）；物理删除；base_url 写死 config。
- `run_cmd` 杀树 best-effort；**`scan_stale_tasks` 权威兜底**（读 DB pid 杀整棵树）。
- **Lookup-Create 幂等**：run_id=sha256(case_ids+timeout) + UNIQUE，存在即返回。

## 已达成结论

- 项目骨架：`pyproject.toml` + `app/core`（config/database/logging/exceptions）+ `models`（2 表）+ `schemas` + `repositories` + `services` + `api/v1` + `utils` + `tasks`（Celery）。
- 执行引擎：`case_generator`（repr 渲染 test_{id}.py）+ `junit_parser`（累加全部 testsuite）+ `report_util`（HTML 报告，无结果也生成）+ `run_cmd`（白名单 + timeout + on_start 落 pid）。
- Celery：`execute_cases` + `scan_stale_tasks`（worker_ready 启动扫描，无 Beat）；Windows `--pool=solo`；显式读 Settings 拼 broker/backend。
- API：cases CRUD + confirm（draft→active 防幻觉）、tasks（Lookup-Create，202）、health；统一 `{code,message,data}`。
- 测试：27 用例全绿（unit/api/tasks，Celery eager + FakeSubprocess 隔离）。
- 验证：**真实异步全链路**（uvicorn + celery worker + Redis + 本地 mock）→ task `success`、passed=1、report_link 生成、Lookup-Create 返回同一 task。
